# CZCE（郑商所）数据入库规范

> 最后更新：2026-07-10

---

## 1. 数据来源

CZCE 结算参数通过 HTTP 直接获取 TXT 文件，**不需要 Chrome**。

**URL 模式：**
```
https://www.czce.com.cn/cn/DFSStaticFiles/Future/{year}/{YYYYMMDD}/FutureDataClearParams.txt
```

**数据格式（管道分隔）：**
```
合约代码|当日结算价|是否单边市|连续单边市天数|交易保证金率(%)|涨跌停板(%)|交易手续费|手续费收取方式|交割手续费|日内平今仓交易手续费|日持仓限额|交易限额
```

## 2. 变更事件规范

### 2.1 版本引用（风险控制管理办法）

| 日期范围 | 引用版本 | 公告字号 | CSRC UUID |
|---------|---------|---------|-----------|
| 全部 | 现行有效 | 郑商发〔2017〕296号 | `4c9e1a74ee104ffda1d681e2571aa34f` |

注：CZCE 风险控制管理办法自 2017-12-22 起持续有效，后续修订均为部分条款修改，第五条保证金阶梯内容未变。

### 2.2 第五条原文

> **自合约挂牌至交割月前一个月第15个日历日期间的交易日：5%**
> **交割月前一个月第16个日历日至交割月前一个月最后一个日历日期间的交易日：10%**
> **交割月份：20%**

注意与 DCE 的区别：CZCE 使用**日历日**（第16个日历日），DCE 使用**交易日**（第15个交易日）。

### 2.3 change_type 规则

与 DCE 相同，见 DCE_ACCESS.md。

### 2.4 source_notice_id 格式

**规则驱动的保证金变更：**
```
《郑州商品交易所期货交易风险控制管理办法》（郑商发〔2017〕296号）第五条
```

**公告驱动的变更：**
```
郑商函〔20XX〕XX号
```

### 2.5 raw_note 格式

```
结算快照确认。依据：《郑州商品交易所期货交易风险控制管理办法》（郑商发〔2017〕296号）第五条中规定"{规则原文}"。{品种} {描述}后保证金由{X}%变为{Y}%。
```

### 2.6 effective_timestamp

与 DCE 规则相同，需要检查各品种是否有夜盘。
