# 旧 Web → /app 迁移台账

审计基线：3866872b7，2026-10-27 Asia/Taipei。本工作区并行存在引擎修改，本台账不审计或修改引擎。

这是首轮 114 个功能项的盘点，覆盖旧路由分发器的全部分支；字段级和权限分支还需要继续细分，不能把 114 当作产品功能总数。

首轮状态统计已过时；以下逐项更新为准，不将未复测条目标为完成。原生实现不等于真实服务验收；不满足删除旧 Web 条件。

本表按可操作功能核对，不能用“已有同名入口”证明迁移完成。状态：**原生**=React 已有对应操作（不等于真实业务验收）；**部分**=只覆盖一部分；**嵌入**=仍依赖旧页面；**缺失**=没有新入口；**待审**=只发现源码，尚未核完行为；**排除**=已退役或外部应用。浏览器示例数据验收不能代替真实 API/Job 验收。
