量化因子工具箱 — 前后端架构、API 接口、因子库说明

1. 项目概览

因子工具箱是一个基于 Flask 的量化因子研究平台，专注于中国期货市场的因子挖掘与验证。系统提供单因子 IC 测试、分组回测、多因子合成等功能，支持参数模板、单因子设置快照等便捷操作。

技术栈

层级技术
后端框架Python Flask (Blueprint 架构)
前端原生 JS + Bootstrap 5.3.2 + Highcharts + MathJax
数据处理Pandas / NumPy / Datascript
运行环境Conda / macOS
数据存储Parquet / CSV / JSON

2. 后端架构

2.1 应用入口 — start_server.py

启动 Flask 应用，默认端口 54865。支持命令行 --port 参数，自动在浏览器中打开首页。提供 /shutdown 路由（仅 Admin 可调用）。

2.2 Blueprint 架构

在 server/__init__.py 中注册 7 个 Blueprint：

Blueprint文件职责
auth_bpserver/auth.py登录/注册/登出，首个注册用户自动为 Admin
core_bpserver/core.py首页(/)、单因子测试、技术文档
templates_bpserver/modules/templates/参数/时间/单因子设置快照模板的 CRUD
shared_bpserver/modules/shared/因子数据、参数管理、产品提交、时间范围
sft_bpserver/modules/single_factor_test/IC 测试、分组回测
cn_futures_bpserver/modules/products/cn_futures/费率获取与管理

2.3 核心路由 — server/core.py

路由方法说明
/GET首页，显示模块导航卡片
/single_factor_test?factor=XGET单因子测试页，加载因子 X 的参数、IC、分组模块
/docsGET本技术文档

因子列表通过扫描 Factors/ 目录中的 .py 文件中定义的类自动发现，按类别（Mm/Oi/Vl/Vp）分组显示。中文名通过类 docstring 的首行提取。

2.4 认证 — server/auth.py

基于 session 的认证。账号与机构层级由 tools/data/account_manage/ 管理；请求运行态由 server/services/runtime_state.py 管理，例如当前用户、页面级时间范围、参数 session 状态等。

2.5 运行态状态 — server/services/runtime_state.py

核心状态管理文件，提供：

函数/变量说明
_tester_cacheFactorTester 单例缓存，按因子名 key
_active_testerContextVar，当前请求的活跃 tester，保证线程安全
params_storedict，按 session 与因子名存储当前参数组列表
current_user()从 Flask session 获取当前登录用户名
get_factor_family_instance()位于 server/services/factor_registry.py，负责实例化因子族类
get_factor_main_section_html()位于 server/modules/single_factor_test/view_helpers.py，渲染单因子测试主页 HTML 片段

模板系统：参数、时间范围、单因子设置快照有独立的 JSON 模板存储（/api/*_templates），支持命名、保存、加载、删除。

前端费率计算：分组回测中的费率敏感性分析在前端用 JS 实时重算累积净值和 Sharpe/MDD，无需重复请求后端。

5. 因子库

平台包含 46 个因子，按驼峰前缀分为四大类别。因子文件名采用 前缀+描述 的驼峰命名（如 MmRSI），前缀即为因子类别，也是单因子测试页面中搜索分类的依据。

每个类别可跳转到单因子测试页面查看具体因子的详细参数、计算公式和回测结果。

📈 Mm — 动量因子 (24个)

方向性动量类因子，捕捉价格趋势、突破、相对强弱、均值回归等价格行为特征。涵盖区间方向动量、均线突破、日内动量、隔夜趋势等子类。

📊 Oi — 持仓因子 (9个)

基于持仓量 (Open Interest) 变化的因子，反映资金流向、持仓结构和多空力量对比。包括持仓变化率、对冲压力、净建仓等子类。

📉 Vl — 波动率因子 (12个)

各类波动率估计量，涵盖已实现波动、下行波动、高低价波动率估计器等。包括 ATR、Garman-Klass、Yang-Zhang 等经典波动率模型。

💹 Vp — 量价因子 (4个)

成交量与价格交互因子，衡量市场流动性、成交活跃度和量价配合关系。包括 Amihud 非流动性、量价相关性、成交额加速度等。

6. 工具类

工具类代码分为五大模块，共 18 个 Python 文件，覆盖了从数据加载、参数管理到因子计算与回测的完整链路。

6.1 基础类 — tools/base/

文件类说明
UniqueObject.py UniqueObject 唯一对象基类。以 (name, 类名) 为键的弱引用单例模式——同名实例全局复用，弱引用确保无引用时可被 GC。所有核心对象（Product、Factor、Parameter 等）均继承此类。
SerialObject.py SerialObject 可序列化对象基类。扩展 UniqueObject，增加 alias 别名系统、类型别名前缀和 pickle 序列化支持。

6.2 数据层 — tools/data/

文件类说明
DataMeta.py DataMeta 数据容器。封装 Pandas DataFrame，透明代理 rolling/pct_change/shift 等操作，自动管理多级时间索引、复权计算、列名映射和品种对齐。
product_ts_data_col.py DataColumn 数据列定义。将 OHLCV 等语义字段与数据源中实际列名映射，支持复权列派生（如 OPEN_ADJUSTED）。
time_freq.py DataFreq 频率定义。封装日/分钟级 K 线频率，支持频率比较、对齐和转换。
DataSource.py DataSource 数据源抽象基类。定义统一的数据获取接口，LocalCNFutures 为其实现。

6.3 参数系统 — tools/parameters/

文件类说明
Parameter.py Parameter, TypeParam, FinRangeParam, TimeDeltaParam 参数系统核心。通过注册表模式将参数定义与值存储解耦，支持值验证、标准化和多参数空间组合（笛卡尔积展开）。
WindowParam.py WindowParam 时间窗口参数。支持 $F=5d、NL=30m 等语法，自动解析为 Timedelta。
DateOrTimeParam.py DateOrTimeParam 日期/时间点参数。用于设定计算起点等时间锚点。
DataColumnParam.py DataColumnParam 数据列选择参数。如 H=HIGH、L=LOW，约束为 DataColumn 枚举值。

6.4 因子引擎 — tools/factors/

文件类说明
FactorFamily.py FactorFamily 因子族基类。定义 func_timeseries 计算接口，实现多品种信号汇总、sync_signal 时间对齐、参数管理及一键测试流程。所有 Mm/Vl/Vp/Oi 因子族均继承此类。
Factor.py Factor 因子实例。包含因子值表、收益率序列、IC 统计量。通过 ContextVar 注入活跃 FactorTester 实现并发安全的结果隔离。
FactorTester.py FactorTester 测试驱动引擎。负责品种筛选、批量 IC 计算（Spearman 秩相关）、分组回测及净值曲线绘制，全程 Numpy 向量化加速。
Parameters.py Parameters 因子参数组。管理 StartCalcPointParam、FactorNextPeriodReturns 等因子系统级参数。

6.5 产品系统 — tools/products/

文件类说明
Product.py Product 交易产品基类。定义合约乘数、最小变动价位、货币等规格属性。
Futures.py Futures, FuturesContract 期货产品。继承 Product，通过 mappings 表维护历史交易日→主力合约映射，支持换月展期和权重复权。
categories/Category.py Category 品种分类体系。树状结构组织（如 黑色→铁矿→i），支持层级遍历和品种聚合。
