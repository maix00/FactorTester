系统架构总览

GTHT 是一个基于 Flask 的量化因子研究平台，采用分层架构设计。

┌──────────────────────────────────────────────────────────────┐
│                    前端 (templates/ + static/)               │
│  Bootstrap 5 + Fancytree + Plotly + Monaco Editor           │
├──────────────────────────────────────────────────────────────┤
│                  Flask Blueprint 路由层 (server/)            │
│  auth · core · shared · single_factor · cf                  │
├───────────┬───────────┬──────────────┬──────────────────────┤
│  因子层   │  产品层   │   参数层      │      数据层          │
│ Factors/  │ Product/  │ Parameters/  │ DataMeta / DataColumn│
│ FactorExpr│ Futures/  │ Parameter/   │ DataFreq / DataSource│
├───────────┴───────────┴──────────────┴──────────────────────┤
│                   数据源 (sources/)                          │
│  LocalCNFutures — 本地 Parquet 文件                         │
└──────────────────────────────────────────────────────────────┘

代码组织

目录/文件说明
start_server.py应用入口：创建 Flask app、启动服务器（开发/生产模式切换）
Settings.py全局配置：默认时间范围、数据路径、交易时段等
server/Flask Blueprint 模块、服务层（auth、accounts、factor_registry 等）
server/modules/功能模块 Blueprint（single_factor_test、products、custom_factors）
server/services/通用服务（API 响应格式、用户存储、运行时状态、热重载配置等）
tools/核心业务逻辑库：因子引擎、产品定义、参数系统、数据层
tools/factors/因子表达式引擎 (FactorExpr)、因子族 (FactorFamily)、因子测试器 (FactorTester)
tools/products/产品基类 (Product)、期货品种 (Futures)、期货合约 (FuturesContract)
tools/data/数据元信息 (DataMeta)、列枚举 (DataColumn)、频率 (DataFreq)、数据源 (DataSource)
tools/parameters/参数系统：基类 Parameter、窗口参数 WindowParam、数据列参数 DataColumnParam
tools/base/基础设施：UniqueObject 单例、IdleResourceManager 缓存回收
Factors/内置因子族实现（46+ 个因子类）
sources/数据源实现（LocalCNFutures、FeeData）
templates/Jinja2 模板 + HTML 页面
static/CSS/JS 静态资源
