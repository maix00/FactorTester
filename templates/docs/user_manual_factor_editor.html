功能概述

因子编辑器允许用户在可视化界面中创建和编辑自定义因子，无需编写 Python 代码。每个用户拥有独立的因子空间，互不干扰。

操作流程

1. 创建因子

点击「新建因子」按钮，填写以下信息：

  • 因子名称：英文标识符，如 MyCustomFactor
  • 中文描述 (desc)：简短中文名称，如"我的自定义动量"
  • 详细说明 (description)：Markdown 格式的因子解释文档
  • LaTeX 公式 (math_expr)：可选，手动指定显示公式；否则自动从表达式推导

2. 定义参数

在参数面板中添加因子参数：

  • 添加参数：点击 + 添加参数，填写别名（如 W）、描述、类型和默认值
  • 参数类型：WindowParam（窗口长度）、DataColumnParam（价格列）、Parameter（通用参数）等
  • 值域：定义参数的有效值范围
💡 系统内置参数：
- $F（信号频率）— 自动添加到每个因子
- $Rev（反转标志）— 自动添加到每个因子
自定义参数别名不要以 $ 开头，避免与系统参数冲突。

3. 构建表达式

表达式编辑器支持以下操作：

表达式类型语法/示例说明
列引用CLOSE_ADJUSTED 或 CA引用数据列
参数引用$P 或 $W引用自定义参数
算术运算(HIGH + LOW) / 2加减乘除组合
滚动运算close.rolling(20).mean()滚动均值
差值P.delta('$F')当前值与 $F 周期的变化
移位P.shift('$F')滞后 $F 周期的值
截面运算cs_rank(factor)对品种截面排名

4. 预览与测试

编辑过程中实时预览 LaTeX 公式；提交并同步后，冻结因子可在因子库与测试工作台中选择。

5. 管理自定义因子

  • 编辑：重新打开编辑器修改因子定义
  • 删除：移除自定义因子
  • 导出/导入：自定义因子以 Python 文件形式存储在用户数据目录下

常见问题

自定义因子和内置因子的区别？

公共因子源码保存在 SQLite 的 factor_family_sources 注册表中，对所有用户可见并由超级管理员维护。自定义因子存储在用户数据目录下，仅创建者自己可见。两者在执行语义上没有区别。

保存后为什么因子没有出现在列表中？

检查因子名称是否与已有因子重复。同时确认因子类正确继承了 FactorFamily 且定义了 factor_expr() 方法。

表达式语法错误怎么办？

保存时系统会验证表达式语法的正确性，如果有错误会给出提示。常见的错误包括参数引用名称不匹配、列引用不存在、运算符使用不正确等。
