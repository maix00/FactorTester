核心前端组件

产品树 (Fancytree)

基于 Fancytree 的树形选择器：

  • 懒加载：通过 lazyLoad 事件向 /get_products 请求子节点数据
  • 多选：selectMode: 3（层级选择），勾选父节点自动选中所有子节点
  • 品种/合约区分：通过 product_type 字段（'product' 或 'contract'）区分节点类型
  • 交互注意：只使用 activate 事件处理节点选中，不使用 click 事件（避免重复触发）

图表 (Plotly)

所有可视化图表基于 Plotly.js：

  • IC 图表：折线图 + 柱状图，带统计标注（均值、±2σ）
  • 分组回测：多系列累积净值曲线
  • 热力图：月度 IC 热力、相关性矩阵

参数面板

动态参数管理 UI：

  • 多组参数：每组参数独立卡片，支持增删拖拽
  • 模板系统：保存/加载参数组合为命名模板
  • 快照系统：一键保存/恢复完整配置（参数+品种+时间+设置）

模块加载机制

前端使用 ModuleManager（定义在 base.js）管理功能模块的加载和生命周期：

// 典型用法（在页面 script 中）
ModuleManager.register({
    init: function() { /* 页面初始化 */ },
    cleanup: function() { /* 页面切换时清理 */ }
});

模块管理器负责：

  • 按需加载 JS/CSS 资源
  • 页面切换时调用旧模块的 cleanup() 防止内存泄漏
  • 用户登录状态变更时刷新模块状态
⚠ 注意：页面间切换不需要整页刷新。前端使用 SPA 风格的模块切换，但每个页面仍是独立 HTML（由 Flask 渲染），ModuleManager 只管理当前页面的子模块生命周期。

AJAX 请求封装

所有后端 API 调用通过统一的 apiCall() 函数：

// base.js 中的定义
async function apiCall(url, method = 'GET', data = null) {
    const options = { method, headers: {} };
    if (data) {
        options.headers['Content-Type'] = 'application/json';
        options.body = JSON.stringify(data);
    }
    const resp = await fetch(url, options);
    const result = await resp.json();
    if (!result.success) {
        if (resp.status === 401) { /* 跳转登录 */ }
        throw new Error(result.error);
    }
    return result;
}
