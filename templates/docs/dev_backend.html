Blueprint 架构

应用在 server/__init__.py 中通过 create_app() 工厂函数创建，注册了以下 Blueprint：

Blueprint模块路径URL 前缀职责
auth_bpserver.auth/auth/登录、注册、登出
core_bpserver.core/首页、各页面路由、文档路由
templatesserver.modules.shared/产品树、价格数据、参数模板等共享接口
sft_bpserver.modules.single_factor_test/single_factor_test/单因子测试页面及 API
cf_bpserver.modules.custom_factors/custom_factors/自定义因子编辑和管理

API 规范

响应格式

所有 API 统一返回 JSON：

// 成功
{ "success": true, ... }

// 失败
{ "success": false, "error": "错误描述" }

认证

除 PUBLIC_ENDPOINTS 中列出的路由外，所有 API 需要登录 Session。公开端点定义在 server/auth.py：

  • auth.* — 登录注册接口
  • core.home / core.docs* — 首页和文档
  • static — 静态资源

共享 API 端点 (modules/shared/)

端点方法说明
/get_productsGET获取产品树数据（支持懒加载子节点）
/api/list_product_namesGET获取所有品种名称列表
/api/get_price_dataPOST获取指定品种/合约的价格数据
/api/load_snapshotPOST加载单因子设置快照
/api/save_snapshotPOST保存单因子设置快照
/api/list_snapshotsGET列出所有快照
/api/delete_snapshotPOST删除快照
/api/save_param_templatePOST保存参数模板
/api/load_param_templatePOST加载参数模板
/api/list_param_templatesGET列出所有参数模板
/api/get_available_freqsPOST获取产品可用数据频率

单因子测试 API (single_factor_test/)

端点方法说明
/get_factorPOST获取因子元信息（desc, math_expr, params）
/runPOST运行完整的 IC 测试 + 分组回测
/generatePOST仅生成因子值（不跑回测）

错误处理

使用 @route_guard 装饰器自动捕获异常并转为 api_fail() 响应：

from server.services.api_response import route_guard

@bp.route('/some-endpoint')
@route_guard
def handler():
    # 任何未捕获异常自动转为 {success: false, error: ...}
    ...
