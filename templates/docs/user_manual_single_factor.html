功能概述

单因子测试是量化研究的核心工作流。用于评估单个因子对未来收益的预测能力。平台提供完整的从 选因子 → 配参数 → 跑IC → 分组回测 的端到端流程。

操作流程

1. 选择因子

左侧因子列表按前缀分组（Mm 动量 / Oi 持仓 / Vl 波动 / Vp 量价）。点击因子名称后，右侧加载该因子的：

  • 因子说明：包含因子公式（LaTeX 渲染）、含义解释、使用提醒
  • 参数面板：当前因子的所有可调参数及其默认值

2. 配置参数

参数面板支持多组参数同时配置：

  • 新增参数组：点击 + 按钮添加一组独立参数组合（每组独立跑一次测试）
  • 修改参数值：直接在输入框中修改，支持下拉选择和自由输入
  • 删除参数组：点击参数组右侧删除按钮
  • 拖拽排序：长按左侧拖拽手柄调整参数组顺序
  • 模板管理：通过"模板"下拉菜单保存当前参数为模板，或加载已有模板复用
  • 单因子设置快照：一键保存当前因子的全部配置（参数+品种+时间+回测设置），方便在多个因子间快速切换对比
💡 常见参数：
- $F（信号频率）：因子信号更新频率，如 1d（日频）、30min（半小时）
- $Rev（反转标志）：True 表示反转信号方向（做空原多头信号）
- W（窗口长度）：计算因子使用的回看窗口
- P（价格列）：使用的价格类型，如 CLOSE_ADJUSTED（复权收盘价）

3. 选择品种和时间

通过树形选择器勾选目标品种，设置测试时间范围：

  • 树形选择器：按「交易所 → 板块 → 品种」三级组织，支持勾选整个板块批量选择
  • 时间范围：支持交易日模式和自然日模式，可分别设置 IC 测试区间和图表显示区间
  • 产品路径模板：保存/加载品种选择方案

4. 运行测试

点击「运行 IC 测试」或「运行分组回测」按钮：

IC 测试

计算因子值与未来收益之间的相关性和 Rank 相关系数：

  • IC 序列图：每个时间截面的因子-收益相关系数时间序列
  • RankIC：Spearman 秩相关系数（更稳健的衡量指标）
  • 累计 IC：IC 的累积和，反映因子方向的一致性
  • IC 统计表：IC 均值、标准差、IR（信息比率）、IC>0 比例等
  • 月度 IC 热力图：各月平均 IC 的热力图
  • 频度 IC 分析：按信号频率分组的 IC 统计

分组回测

按因子值将品种分成若干组，评估各组未来表现：

  • 多空净值曲线：做多最高组、做空最低组的累积收益
  • 分组收益柱状图：各组平均收益
  • 费率敏感性分析：不同费率假设下的损益变化
⚠ 注意：分组回测默认使用日频调仓（$F = '1d'），如果因子信号频率更高（如 30min），会自动对齐到日频。多品种组合以等权方式构建。

常见问题

为什么 IC 值为空？

可能是品种选择太少（至少需要 3 个以上品种才有统计意义），或者起始时间点没有足够的数据。检查数据源是否正确，以及 StartCalcPoint 是否设置合理。

如何同时对比多组参数？

在参数面板中添加多组参数（如 W=10 和 W=20），运行测试后图表会自动叠加显示不同参数的曲线。

复权价格和非复权价格有什么区别？

期货合约换月时价格会跳空。复权价格（CLOSE_ADJUSTED）通过乘数/加数消除了跳空，更适合计算收益率和趋势类因子。
