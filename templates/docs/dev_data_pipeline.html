数据流概览

数据从底层文件到前端图表的完整链路：

┌──────────────────────────────────────────────────────┐
│ Parquet 文件 (sources/LocalCNFutures/) │
│ ↓ │
│ DataSource — 注册数据源，定义文件→列名映射 │
│ ↓ │
│ Product — 品种/合约对象，持有各频率 DataMeta │
│ ↓ │
│ DataMeta — 封装 DataFrame，提供列名映射、复权、时间切片 │
│ ↓ │
│ FactorExpr.evaluate() — 表达式树从 DataMeta 取数求值 │
│ ↓ │
│ FactorFamily.get_factor() — 参数解析 → SignalAlign │
│ ↓ │
│ FactorTester — IC 计算 / 分组回测 │
│ ↓ │
│ 前端 Plotly 图表渲染 │
└──────────────────────────────────────────────────────┘

各层详解

1. DataSource — 数据源注册

tools/data/DataSource.py 中的 DataSource 类定义数据源元信息：

  • freq：数据频率（MIN1 / DAY1）
  • 包含的产品列表：决定哪些 Product 可以使用该数据源
  • data_cols_mapping：Parquet 列名 → DataColumn 枚举的映射
  • path：Parquet 文件路径

数据源实例通过 DataSource.__init_subclass__ 自动注册到全局列表。

2. Product — 产品对象

tools/products/Product.py 中的 Product 是抽象基类：

  • 持有各频率的 DataMeta 对象（如 product.MIN1、product.DAY1）
  • Futures（品种）通过 roller_info 表维护历史交易日→主力合约映射
  • FuturesContract（合约）直接对应具体到期合约

3. DataMeta — 数据元信息

tools/data/DataMeta.py 是数据访问的核心封装：

  • 懒加载：get_data() 首次调用时从 Parquet 读取 DataFrame
  • IdleResourceManager 缓存：DataFrame 缓存由 IdleResourceManager 管理，闲置 5 分钟后自动释放
  • 列名映射：通过 DataColumn 枚举访问列（如 df['CLOSE_ADJUSTED']）
  • 时间索引：构建 (Date, Time) 的 MultiIndex
  • 复权计算：通过 ADJUSTMENT_MUL / ADJUSTMENT_ADD 列计算复权价格
  • day_periods：缓存每日 bar 数，用于信号对齐

4. FactorExpr — 表达式求值

tools/factors/FactorExpr.py 定义表达式树：

  • 节点类型：ColumnRef（列引用）、ConstExpr（常量）、ParamRef（参数引用）、RollingOp（滚动运算）、CompositeExpr（复合运算）等
  • 求值：evaluate(freq, dm) 从 DataMeta 中取对应列，执行运算
  • 中间因子缓存：通过 as_intermediate(name) 为命名中间结果，跨 Product 复用
  • LaTeX 生成：to_latex() 递归生成公式字符串

5. FactorFamily — 因子族

tools/factors/FactorFamily.py 连接参数和表达式：

  • 声明式定义：子类实现 factor_expr() 静态方法，返回含 ParamRef 的表达式树
  • 参数解析：_resolve_expr_params() 将 ParamRef 替换为具体值，生成纯表达式树
  • Factor 生成：get_factor() 创建 Factor 实例（已解析的表达式+数据）

6. FactorTester — 测试引擎

tools/factors/FactorTester.py 执行回测分析：

  • CrossSectionalEval：对多产品批量求值因子表达式
  • IC 计算：Spearman 和 Pearson 相关系数
  • 分组回测：按因子值分组，模拟多空组合收益

数据源列名映射

Parquet 文件的原始列名通过 DataSource.data_cols_mapping 映射到 DataColumn 枚举：

DataColumn代号中文名Parquet 列名示例
OPENO开盘价open
HIGHH最高价high
LOWL最低价low
CLOSEC收盘价close
VOLUMEV成交量volume
TURNOVERTO成交额turnover / amount
OPEN_INTERESTOI持仓量open_interest

复权价格列（OPEN_ADJUSTED、CLOSE_ADJUSTED 等）不直接从文件读取，而是由 DataMeta 通过 ADJUSTMENT_MUL 实时计算。
