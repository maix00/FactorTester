快速入门

1. 登录系统

首次使用点击首页右上角「登录/注册」创建账号。首个注册用户自动成为管理员，可管理其他用户。

2. 选择因子

进入「单因子测试」页面，左侧因子列表按类别（Mm动量/Oi持仓/Vl波动/Vp量价）分组。点击因子名加载其参数和测试配置。

3. 配置参数

每个因子有自己的参数组（如窗口长度、计算方式）。参数支持新增、删除、拖拽排序。可保存为模板方便复用。

4. 选择产品和时间

通过树形选择器勾选目标品种（支持按板块批量选择），设置测试时间范围。支持交易日/自然日模式。

5. 运行测试

点击「运行IC测试」或「运行分组回测」查看结果。IC图表展示因子与未来收益的相关性；分组回测展示多空组合的累积净值曲线。

💡 提示：参数模板和单因子设置快照可以保存当前所有配置（参数+时间+品种+回测设置），方便在不同因子间快速切换对比。

因子体系

平台包含 46+ 个因子，按前缀分为四大类别：

类别前缀数量说明
动量因子Mm*24趋势、突破、RSI、MACD、日内动量等价格行为特征
持仓因子Oi*9持仓量变化率、对冲压力、净建仓等资金流向指标
波动率因子Vl*12ATR、Garman-Klass、Yang-Zhang 等各类波动率估计量
量价因子Vp*4Amihud非流动性、量价相关性、成交额加速度等

每个因子类包含 description_sections（因子说明）、math_expr（LaTeX公式）等属性，在因子详情页自动渲染。

公共操作说明

参数管理

所有因子测试共享统一的参数管理界面：

  • 新增参数组：点击「+」按钮添加一组新参数
  • 删除参数组：点击参数组右侧的删除按钮
  • 拖拽排序：长按参数组左侧拖拽手柄调整顺序
  • 模板保存/加载：通过「模板」下拉菜单保存当前参数为模板，或加载已有模板
  • 单因子设置快照：一键保存/恢复当前因子的完整配置（参数+时间+品种+回测设置）

时间范围设置

支持两种模式：

  • 交易日模式：按交易日历选择起止日期
  • 自然日模式：按日历日期选择

期货品种支持分别设置日盘和夜盘时间，确保跨夜交易的收益率计算准确。

产品选择

树形选择器按「交易所 → 板块 → 品种」三级组织。支持：

  • 勾选/取消单个品种
  • 勾选整个板块（批量选择）
  • 搜索品种名称
  • 产品路径模板保存/加载
