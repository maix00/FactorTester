## 常用对象及边界 {#core-objects}

TradeResearch 把可编辑页面、协作研究、执行任务和研究报告分别建模。它们可以通过稳定引用关联，但不能因名称相似而互相替代。

| 对象 | 主要用途 | 生命周期边界 |
| --- | --- | --- |
| Profile | 表示执行研究工作的身份 | 一个用户可以有多个研究身份；名称不是授权主体 |
| Workspace | 提供某次工作使用的配置和资源视图 | 不自动成为全局对象的所有者或授权范围 |
| Research Workspace | 保存某个 Profile 在一个 Research 中的上下文和协作状态 | 不等于因子工作区，也不构成新的全局因子库 |
| Report | 保存结构化报告并支持受控发布 | 可以独立授权和阅读；不等于整个 Research |
| ReportBranch | 表示报告正文的一条可编辑版本线 | 修改分支不改写已发布版本 |
| RunSpec | 冻结一次任务的配置和输入引用 | 提交后不可由编辑器草稿改写 |
| Job / Attempt | 分别表示用户可见的任务和一次实际执行 | 重试保留旧执行记录，形成新的历史 |
| Artifact / Evidence | 分别表示任务输出和可复用的研究事实 | Evidence 必须显式绑定来源；Artifact 仍由其存储端管理 |

## 选择引用、草稿或快照 {#reference-vs-copy}

复用已登记对象时使用稳定 ref，并检查所有者、版本和权限；尚未提交的页面状态保存在草稿中；需要回溯的执行事实通过 RunSpec、Job、Attempt 和 Artifact 的关联读取。复制显示名称、源码或 JSON 会丢失版本、来源和授权语义，不能替代正式引用。

领域对象的协作关系见[研究、报告与证据](/docs/research-model)，任务执行关系见[运行配置、任务与生成物](/docs/runspec-job-artifact)。
