## 先确认数据范围 {#confirm-data-scope}

在“产品库”的数据源页面确认数据源能提供哪些产品、字段、交易时段、币种和历史覆盖。数据源家族、成员和字段能力是不同层次；能看到产品不代表该成员能提供所需历史字段。产品分类是组织和筛选辅助，默认不等于运行范围；只有显式选择的产品路径或产品路径组才进入 RunSpec。

候选列表为空时先区分三种情况：没有对象、对象对当前身份不可见、或数据能力服务暂时不可用。不要把空列表直接解释成数据库没有数据，也不要以服务器目录扫描代替正式查询。

## 选择产品路径 {#choose-product-paths}

产品路径描述产品分类或具体产品的选择，数据源与执行节点另行绑定。一次测试可以选择多个路径，也可以在配置页当场建立产品组。提交前检查日夜盘、复权、换月、历史费率、价格字段和历史覆盖是否符合研究问题，不要用分类名称代替实际产品范围。

配置页新建的产品组保存为可复用对象，草稿写入其稳定引用。提交时冻结稳定引用、解析后的选择范围和来源 revision；UI 显示名称变化不能改变已经提交的历史事实。一个资金池可以包含不同币种的账户，但这不应被错误地压缩为产品路径或单一币种字段。

## 使用对象目录 {#object-directories}

产品库提供列表和产品树。产品树展开时按需读取子项，每页 50 项，通过分页切换；搜索查询整个授权目录。浏览模式点击产品进入行情详情，选择模式则勾选产品或产品路径。翻页、搜索、折叠和刷新不会清除选择，也不会为勾选一个目录枚举全部后代。

产品组和产品分类条目复用同一个多选界面。勾选目录后，其未加载的产品也包含在规则中；产品组取消其中一项时记录排除路径，重选整个目录会清除该目录下的排除项。“高级路径编辑”中每行一条规则，以 `-` 开头表示排除。当前不可见或历史路径继续保留，保存时由服务器校验。分类条目仅支持正路径，需先调整父目录规则再选择部分后代；系统生成的补集不可修改，乘积分类仅允许修改普通条目名称。

测试配置的产品组字段可以打开同一编辑器新建产品组，保存后使用产品组引用。产品勾选不隐含选择某份数据。执行位置中的 Bundle 与所有者用于限定匹配范围；匹配结果显示实际 Manager、节点、安装实例和版本。同名 Bundle 在不同节点或不同安装中保持独立，运行前仍须核对数据覆盖和源成员。

因子库分别提供因子、家族和集合。家族页面编辑源码与说明；因子页面编辑参数并由服务器生成新的冻结引用；集合页面选择具体因子，保存时保留成员的冻结定义。名称用于显示，版本引用用于执行，两者不能互相替代。对象中的用户、产品与因子引用可打开对应信息。

### 因子家族与因子详情 {#factor-family-detail}

家族详情分为概览、源码、版本和成员因子。源码按需读取；选择历史版本或输入完整版本指纹可查看对应快照。成员表中的因子可直接打开详情。删除或转换家族归属前会显示受影响对象，确认后按服务端权限与版本校验执行。

因子详情的参数表区分默认值与实际参数值；引用嵌套因子的值可点击查看。历史源码的版本身份保持冻结，使用新引擎生成展示公式不会改变它。

策略库提供独立的新增、详情和编辑界面。详情按需读取源码，版本表打开冻结快照；编辑生成新版本。策略链接按完整引用读取，不依赖列表当前分页；所有读取、编辑和共享操作由 Keycloak 校验。

## 选择或提供因子 {#choose-factors}

因子家族是发现和参数化入口；具体因子和 FactorSet 才是可以冻结到 RunSpec 的研究对象。选择 FactorParam 时，候选可以来自数据列、因子库或当前页面新建的嵌套因子，但解析后要记录具体 ref、参数和源码版本。能被语法解析但不在因子库中的 alias 必须明确标记为临时构建，不得伪装成已登记对象。

Web 端搜索当前身份有权看到的公共、下级或本人的因子；macOS 客户端还可选择本地因子工作区。临时上传的 Python 因子源码属于 Job 输入，会按保留策略与任务一起保留，并在任务详情中展示来源和完整性信息。

参数编辑器使用家族声明的类型、枚举与默认值。FactorParam 可选数值、数据列或已登记因子，也可打开公共信息面板新建内层因子。选择内层因子时读回完整冻结定义，完成后才允许保存；JSON 与常规表单编辑的是同一份参数。保存参数变化生成新的因子引用，不能覆盖历史冻结身份。

家族源码可从 Python 文件导入，并显式校验、预览公式与参数。导入文件只填入草稿，保存才写入服务器。超级管理员可选择公共家族；普通用户创建自己的家族，权限由 Keycloak 和服务器再次核验。

## 上传前的来源核对 {#source-check}

因子库工作区与数据库同步时，先下载当前权威版本并检查冲突，再上传用户确认的变更。服务器 Profile 的工作区副本与客户端遵守相同的对象引用规则，但副本的写入不应绕过用户工作区的授权流程。研究身份工作区是用户工作区的副本或分支视图，不是新的权威因子库。

## 运行前清单 {#input-checklist}

确认因子 ref 和源码版本、FactorSet 成员、产品路径、数据源字段、交易日历、费率/保证金历史、时间区间和时区。任何“自动”选择都要在预览或提交后的冻结配置中找到最终解释；候选为空时先检查权限和数据能力，不要用文件名猜测对象。

准备完成后进入[运行 IC 测试与回测](/docs/run-tests)。
