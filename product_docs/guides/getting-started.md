## 平台由什么组成 {#platform-parts}

FactorTester 把产品与数据源、因子、测试任务、研究报告分成独立对象。Web 客户端适合访问服务器公开内容；macOS 客户端还能读取当前用户机器上的本地研究与本地数据源。

## 第一次使用 {#first-use}

1. 在“产品”确认研究对象和数据可用性。
2. 在“因子库”找到已有因子，或准备本地因子家族。
3. 从“测试”选择 IC 测试或回测，检查默认运行配置后提交。
4. 在“测试任务”查看进度、结果、生成物和实际冻结的运行配置。
5. 需要形成可审计结论时，从“研究”进入结构化研究报告。

下一步可阅读[运行 IC 测试与回测](/docs/run-tests)。

## Web 与 macOS 客户端的区别 {#client-differences}

服务器只声明服务器能够提供的资源。macOS 客户端可另外展示本机的数据源、因子工作区和本地研究，但不会把这些本地能力伪装成服务器能力。
