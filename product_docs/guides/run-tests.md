## 选择核心研究对象 {#select-subjects}

先选择因子或因子集合、产品路径或产品路径组，以及 delay、horizon 等核心维度。IC 测试会为这些组合建立核心测试条目；附加分析依附于明确的核心条目或另一个分析条目。

## 配置测试 {#configure-test}

“＋设置”中的每个设置页来自后端注册的字段协议。没有挂载的设置使用其注册默认值；条件不适用的字段不会进入提交。回测中的分组、多空和自定义策略使用策略列表单独管理，但最终冻结在同一运行配置中。

## 提交与执行 {#submit-run}

提交时平台冻结 RunSpec，再创建 Job。任务名称可以为空；服务端口是执行路由，不属于策略语义。任务详情中的“运行配置”展示实际执行的冻结内容，而不是当前编辑器里后来改变的草稿。

对象之间的区别见[运行配置、任务与生成物](/docs/runspec-job-artifact)。
