\chapter*{读者指南}
本手册先按用户实际操作顺序介绍登录、准备输入、运行研究和发布报告，再说明支撑这些流程的领域模型与系统架构，最后汇总接口、验收和运维方法。

研究人员可从第一部分开始；客户端和服务端开发者可先阅读第二部分，再查阅第三部分的接口与字段契约；测试和发布人员可直接阅读第四部分。每章标出适用读者和阅读目标；来源路径、Git 状态与内容摘要统一列在附录，正文不再重复版本元数据。
