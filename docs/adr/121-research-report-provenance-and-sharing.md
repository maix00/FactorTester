# ADR 121: 研究报告构建来源与共享状态分离

## Context

研究报告可以由 FTClient 在本地 Profile 工作区构建，也可以由绑定到
服务器的 Agent 在服务器 Profile 工作区构建。报告是否被发布给其他用户是
另一维度；把“服务器上的报告”直接当成“共享报告”会泄露访问语义，也无法
表达客户端创建但尚未发布的报告。

## Decision

报告元数据同时保存两组字段：

- `build_source` / `build_source_ref`：`client` 或 `server_agent`，表示构建
  运行时及其稳定引用；
- `sharing_state` / `is_shared`：由 `visibility` 派生为 `shared` 或
  `not_shared`，表示访问策略，不表示文件存储位置。

服务器 Agent 报告直接读取服务器 Profile 的规范研究树；只有用户显式发布
时才复制到公共研究库并进入跨服务器共享链路。共享元数据可以跨服务器同步，
报告正文和对象仍由其存储 Manager 提供。旧发布记录缺少新字段时，按客户端
构建、根据既有 `visibility` 推导共享状态；新的写入不允许改变已有报告的
构建来源或来源引用。

## Consequences

报告列表必须分别显示“构建来源”和“共享状态”，同时保留具体访问范围。
服务器 Agent 报告可在未共享时由所有者从其服务器打开，发布后使用既有公共
研究对象数据面跨服务器读取。业务测试端口不参与报告读取。
