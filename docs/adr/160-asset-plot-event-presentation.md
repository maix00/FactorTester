# ADR-160 — 交易图的事件呈现与账本边界

状态：已接受（Issue #438）。

## 决策

Asset Plot 是回测 Job 的「交易与账户」结果视图，不是弹出的独立 overlay。订单和成交按 Job 保存的事件记录绘制；价格来自当前行情源，因此图上行情与回测时的行情可能不同。下方逐笔记录复用公共分页表格，横向空间不足时表格自身滚动。

同一绘图时间戳、同一价格位置的事件合成一个标记，标出笔数；订单与成交混合时使用中性颜色。点击标记后，表格筛出该组的**全部**独立事件，保留逐笔 ID、方向、数量、价格与账本变化；可恢复全部事件列表。同一时间但不同价格的事件仍各占一个点。图表时间轴以毫秒呈现，原始高精度时间仍由 Job 生成物保留，不把图表重合解释为账本合并。

悬浮其中一个标记时，其他标记保持原来的颜色与不透明度。提示最多预览六笔，完整列表由表格分页承载。

## 账本语义

手续费、现金、保证金和持仓的「之前 → 之后」只能使用同一事件里真实记录的 before/after 字段。订单的最终剩余量与终止未成交量必须标作最终状态，不能冒充某笔成交后的实时剩余量。缺字段显示「未记录」，不根据成交量臆造持仓或现金。保证金为零的全额交易不显示为保证金交易。

`cash_detail_data`、`position_detail_data` 和 `margin_detail_data` 可能是采样曲线，而非独立事件；当前不把每个采样点画成事件标记。成交造成的保证金变化附在该成交的账本说明内。将来若有独立追加/释放保证金、资金划转或风控事件，必须先有稳定事件 ID、精确时间、来源及前后账本状态，再加入同一事件查询与标记分组，不能从快照差值逆推事件。

## 验收与回退

浏览器测试覆盖同点分组、异价分点、点击后的逐笔筛选、真实 Highcharts 标记及其他标记不淡化；还覆盖结果页而非 dialog、公共表格和缺失保证金字段的呈现。回退 Issue #438 的任务提交即可恢复原 Asset Plot overlay，不涉及数据库或 Job 生成物迁移。
