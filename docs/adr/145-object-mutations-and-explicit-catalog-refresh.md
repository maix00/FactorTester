# 145 — 对象写入与显式目录刷新

状态：实现中；真实部署与运行验收未完成。关联 #373、ADR 144。

## 已确认的问题

单因子编辑使用整家族替换接口；强制刷新仍立即读取旧镜像；一个无效 provider
使 outbox 后续记录无法发送。策略库没有接入统一目录同步。固定端口发现可能
把新 Manager 连接到旧 checkout 的写服务。

## 决策

- 单因子写入使用追加或带原冻结 ref 的替换；编辑目标不存在时拒绝。复用其他
  行的冻结记录，只计算变化的参数行，避免改动家族源码时重新解释历史因子。
- 配置、冻结镜像和 outbox 在同一个 SQLite 事务提交。旧的原始配置写入口暂时
  保持兼容，需要冻结后才能发送；不允许把原始草稿当作空目录发布。
- 暂时保留家族配置 JSON，列表和候选读取 ADR 144 的持久投影。按因子独立写入
  的 schema 迁移须先测量真实家族规模下的 SQLite/JSON 写放大，不能仅凭推测改库。
  当前单行编辑的编译次数已用 100 行隔离回归验证为 1；这不是线上耗时测量。
- account-domain 是元数据同步基础设施；普通列表异步调度，显式刷新通过共同
  barrier 返回完成、未完成或失败。脏写发生于在途刷新时再执行一轮。单条无效
  outbox 留存错误且继续处理其余条目；冲突不自动覆盖。
- legacy reconciliation 只回填没有镜像的实体，不能用旧 authored 副本复活删除。
- 策略入口和 revision 元数据进入 account-domain；源码仅在详情、编辑、运行
  冻结时通过 7997 下载并验证大小、对象 hash 和源码 hash。列表不取源码。
- revision UUID 是策略版本身份；序号是展示字段。离线节点可各自产生序号 2，
  SQLite 移除 `(strategy_ref, revision_number)` 唯一限制，保留两个版本；当前
  入口由 account-domain CAS/冲突机制决定。迁移事务保留所有原有列与记录。
- 下拉框统一使用 viewport 坐标与 popover top layer，优先向上展开；空间不足
  才向下展开。滚动、视觉视口与元素尺寸变化重定位，关闭和卸载释放监听器。
- 临时候选由调用页面持有；下拉框修改必须回传完整冻结对象和选中引用。草稿
  与运行配置复用临时对象快照；overlay 使用独立 pageState，不能复用父表单键。

## 上线条件与回退

必须核对 7998/7999/7997 实际 checkout，完成双向对象 CRUD、权限/冲突/删除、
临时对象刷新恢复、所有测试配置生成与真实运行、智能体辅助填写的验收矩阵。
发布前备份 SQLite 与现有源码。旧版本可以读取迁移后的 revision 表，但其旧
同步/写入缺陷仍然存在；回退不是数据修复方案。CA 历史恢复必须保留新旧两行，
在验收完成前不删除仍用于恢复或回退的备份。
