# ADR 009: 单因子提交状态按页面作用域隔离

## 背景

同一登录 session 可以同时打开多个单因子测试页面。每个页面通过 `page_uuid` 持有自己的时间范围和产品提交列表，但所有 `FactorTester` 当前共享保存在进程内的 `runtime_state.factor_testers`。若某个变更接口返回全局 submissions，前端会把别页提交同步到当前页；若排序接口直接用当前页顺序覆盖全局列表，还会删除别页的运行时 tester。

## 决策

- `page_uuid` 是产品提交视图与变更操作的作用域键；前端的提交新增、更新、改名、路径删除、提交删除、排序及 IC 提交解析请求均携带当前 `page_uuid`。
- 后端收到 `page_uuid` 时，仅可查找、修改和返回归属于该页的 tester；不同页即使处在同一 Flask session 中也不可互相变更。
- 排序只替换全局列表中当前页 tester 所占的位置，并保持其他页 tester 的对象和相对顺序。
- 未携带 `page_uuid` 的请求暂保留旧全局行为，服务旧客户端；新的单因子页面代码不得省略该参数。

## 结果

- 模板导入、提交编辑与排序不再导致产品筛选提交区跨页污染。
- 同一 session 多页面可以并行维护各自的提交及测试结果。
