# ADR 057：7997 生成物与提交物数据面

## 状态

已接受；跨节点传输部分由 ADR-068 修订。

## 决策

1. 每台服务器的 7998 是控制面，负责任务路由、权限校验、元数据和短时下载票据；每台服务器的 7997 是主机级数据面，负责生成物与提交物的 `GET`、`HEAD` 和 HTTP Range/断点下载。
2. 文件继续保存在实际运行任务的服务器上。SQLite 只保存文件的 owner、任务、角色、哈希、大小和相对路径等元数据，不通过复制 SQLite 文件实现跨服务器 active-active 同步。
3. 7998 为本机 7997 或跨节点 Transfer Attempt 签发短时票据。票据绑定用户、任务、文件名、节点角色、字节范围和过期时间；7997 不接受仅凭路径读取或写入文件。
4. 客户端只访问当前 Manager 所属节点的 7997。跨节点时按 ADR-068 经 WireGuard 17998/17997 直连；不会把客户端重定向到另一个节点的内部地址，也不存在 7998 字节回退。
5. 任务列表和详情同时展示生成物、提交物的数量和占用空间。当前这些统计是本地 SQLite 的活动文件投影；跨服务器总配额的最终扣账仍应由统一的配额权威服务完成，不能用各节点本地统计相加后直接放行写入。

## 结果

- 大文件传输不会被 Base64 编码后挤占 7998 联邦控制链路，并支持浏览器/客户端断点下载。
- 任务节点离线时，控制面可以明确报告数据面不可用；文件不会被错误地从另一个节点的同名路径读取。
- 旧 7998 字节兼容路径已经移除，生成物与提交物字节只走数据面。
- 跨节点传输、WireGuard 节点控制和 PostgreSQL 故障语义以 ADR-068 为准。
