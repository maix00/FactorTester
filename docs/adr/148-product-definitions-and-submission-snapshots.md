# ADR 148：产品组定义与提交时产品快照

状态：实施中（refs #381）

## 已测事实

原产品组同时保留 selection_paths 与展开 paths，列表加载会重新解析并写回。这样会把动态分类引用与当前成员混在一起。2026-09-07 公网 MaxJJW 盘点中，日盘和夜盘定义均已保存为成员叶子路径；历史展开记录不能仅凭当前成员推断原始选择意图。

## 决策

产品组 paths 保存带符号的分类/Label 引用，selection_paths 仅为现有编辑器的兼容投影。列表不展开成员、不执行写回；显式编辑才持久化。继续复用 account-domain outbox、镜像及删除机制。

测试草稿手选产品时携带选择的路径；选择产品组时携带稳定身份。共享 frozen_product_scope 在提交侧解析当前定义为精确叶子路径，不缩并为成员会变化的父路径。同时保留 definition_paths、分类身份与 resolution_sha256。执行器和重试沿用冻结的 JobSpec，不查询当前库来重建旧范围。

通过现有 input_artifacts 保留 product_scope_snapshot.json，供各测试类型共用。详情页使用共享可分页表格列出精确产品及所属选择。缺少历史快照的任务明确标记，不能用当前库补造历史事实。

手选候选遵循统一外层数据源、产品分类和产品组约束；混合外层产品组和手选产品取并集，再与分类及数据源范围相交。分页接口需读完匹配页，不能静默只保留第一页。

## 验证与发布

分类成员改变后，新提交范围变化，旧提交不变；正负分类引用仍原样持久化。测试覆盖混合来源候选、分页、身份投影、生成物保存及任务重试。生产修复先保存原对象和映射；无法还原意图的历史选择不猜测转换。双端对象 CRUD 与实际运行验收后才标记完成。

本决策补充 ADR 116 的产品解析和不可变运行输入边界，不新增数据库 schema 或同步协议。
