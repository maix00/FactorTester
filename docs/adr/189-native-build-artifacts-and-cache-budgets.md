# ADR 189：原生构建产物与有限缓存

状态：实施中，2026-10-28。

## 决策

源码发布与原生编译解耦。原生构建身份由 Nautilus、alpha、组合运行时源码及目标平台决定；普通 Web/Python 更新不重编译 Rust。成品校验后复用，源代码变化由同一个 Cargo target 增量编译，构建串行化以防缓存争用。镜像的系统依赖/CLI 工具层先于原生包层。

wheel 不继续作为每次发布的 Git 二进制改动；用 BuildKit 命名上下文接收独立、校验过的 alpha 与组合 Nautilus wheel。发布前确保目标主机有对应身份的产物，网络只在缺失或校验失败时传输。服务切换前完成包导入检查；缺包阻止发布，不回退旧 Python 执行路径。

## 存储与失败行为

本机默认 Cargo target 预算 4 GiB；完成的成品包优先于编译缓存。仅自动淘汰脚本拥有的超预算 target，外部指定路径不删除。临时 archive 结束即删除，保留一份内容稳定的源码快照和依赖下载缓存。公网不编译 Rust；产物按构建身份存放，当前与回退版本仍被引用时不得删除。不做全局 Docker prune，不以构建优化为由删除 Bundle、用户生成物、数据库或备份。

## 验证

记录缓存 hit/miss、构建身份、耗时、峰值资源限制与占用。验证相同输入命中、改变输入失效、损坏产物拒绝、并发构建互斥，以及源代码发布不使无关依赖层失效。合成缓存测试不代表真实部署耗时；新旧 wheel 的真实运行验收另行记录。
