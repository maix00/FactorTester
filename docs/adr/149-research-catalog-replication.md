# ADR 149：研究关系目录的跨服务器同步

状态：实施中（refs #382），尚未完成双端部署验收。

## 问题与边界

服务器助手通过 CLI 新建研究、撰写报告、绑定并运行测试后，公网目录存在该研究，内网按同一 research_id 查询却不存在。已有 research_publication 同步的是报告可读投影，不能替代研究根对象、成员、工作区及报告关系。报告提交后的通知还依赖固定本地地址和文件路径中的用户身份，在服务器沙箱中不能成立。

## 决策

复用 account-domain 的 SQLite outbox、控制库 revision、冲突记录与异步刷新。一个 research_catalog 对象保存一项研究的关系快照；原业务记录与 outbox 在同一个事务内提交。新建、编辑、归档、成员撤销和分享兑换后的授权变更均经过这一入口。缺少本地记录不产生删除。离线编辑保留待发送项，版本冲突沿用显式解决机制，不使用无条件覆盖。

快照仅含目录关系，不含报告正文、生成物字节、分享令牌或其摘要。正文继续由已有报告投影和 7997 数据链路提供。服务器助手的报告通知使用注入的 Manager 地址及短期授权，由 Manager 确认 owner，不从 /workspace 路径猜测身份。通知失败不能回滚已保存的报告。

复制范围与用户可见范围分开：现有控制库使用 visibility 字段筛选复制记录，本对象以 public 复制信封加 replication_scope=trusted_managers 传播到受信任 Manager，使权限撤销也能到达以前缓存过授权的服务器。这个信封不授予用户公开访问；业务 visibility、owner、成员和授权用户仍位于 research 字段内，所有用户读取必须经过 ResearchCatalog 的权限判定。不得把原始复制信封暴露给客户端。

快照遵守现有 512 KiB 上限，超限事务失败，不能截断关系。列表读取仅触发已有异步刷新，不等待跨服务器 I/O。未变 revision 不重建目录。初次补登记只处理本机原生且尚未有同步信封的记录；历史迁移对象需单独核实来源，不能由每台镜像服务器自行认领。

接收的是完整关系快照，必须包含全部关系集合；缺集合的报文拒绝应用。接受新版本或显式解决冲突后，本地关系投影应与所选快照一致，移除快照之外的旧关系，避免残留授权和重复工作区。这个事务只更新目录关系，不删除报告字节、生成物或发送全局删除记录；尚有本地待提交冲突时不执行覆盖。

## 验证与发布

聚焦测试覆盖同身份集合传播、归档、撤销访问、共享授权、离线冲突、事务回滚与跨对象身份覆盖防护。报告通知测试验证服务器沙箱无用户路径时仍使用注入授权，Manager 暂时不可用时不破坏本地提交。这些测试不等于真实双端验收。

发布前保留目录备份，核对原生与历史迁移记录的数量、身份和未处理冲突；上线后用隔离研究验证新建、成员绑定、报告更新、运行绑定与归档在两端收敛。回退代码时保留研究业务表和 outbox，不以删除研究或报告消除不一致。
