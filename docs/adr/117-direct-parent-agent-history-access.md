# ADR-117：直属上级默认只读查看下级 Agent 会话

## 状态

已接受

## 背景

研究身份目录按用户层级展示直属下级 Profile。下级 Profile 的 Agent
会话属于该 Profile 的工作记录；直属上级需要能够审阅这些记录，但不应
获得下级工作区或 Agent 的控制权限。旧实现要求下级额外打开
`conversation_sharing` 开关，导致目录中的会话可见性与用户层级关系不一致。

## 决策

- 直属下级 Profile 的 Agent 会话对直属上级默认可见。
- 上级读取会话及会话内容始终是只读，不能通过该目录启动、停止、删除
  Agent，也不能修改下级文件。
- 超级管理员继续按既有规则拥有只读查看权限。
- 非直属上级仍须满足原有 Profile 可见性规则。
- 会话正文只从 Profile 执行/来源 Manager 的 Provider thread 按 turn 分页读取；
  请求方不扫描所有服务器、不合并正文副本，也不在源不可达时回退到旧缓存。
- 上级与所有者使用同一套 ChatKit 原生 item。上级 thread 标记为 locked，所有
  新建、提问、重命名、删除和停止操作都被拒绝；历史分页和“结果/过程”懒加载
  保持可用。
- `conversation_sharing` 的历史字段和存储表暂时保留以兼容旧数据，但不再
 参与直属上级的访问判定；前端不再展示“向上级公开”开关。

## 结果

Profile 目录的直属下级列表可以稳定展示其会话数量，并且会话读取不会因
下级是否执行过旧的公开操作而产生不一致。跨服务器请求沿用同一权限判定，
数据来源服务器只提供只读会话投影。
