# 146 — 因子家族历史版本使用独立提供方元数据

状态：采用。关联 Issue #373。

跨服务器验收复现：家族在本机从 v1 编辑到 v2，未加载过 v1 的公网请求 v1 返回 503。当前提供方记录只表示最新源码可用性，不能用于定位历史不可变版本。

每个服务器为实际持有的公式版本发布独立 `factor_source_version` 元数据，身份为家族、公式指纹、提供方。记录仅包含指纹、源码哈希、字节数和显示摘要，不携带源码。版本正文与本机 outbox 在同一 SQLite 事务写入；已有历史记录在统一同步边界按元数据补登记。

详情版本列表读取本机已同步的元数据，选中历史版本时通过现有 7997 数据面按授权哈希读取版本正文。原点以拥有者、家族和哈希共同定位，接收端再校验字节数、哈希与语义指纹。拉取历史版本只记录历史快照，不覆盖当前源码或当前家族指针。权限判断不依赖当前源码是否已缓存在接收端。

历史版本保留给已冻结的引用使用；删除家族仍使常规家族列表与当前详情不可用。版本提供方记录不参与当前家族列表投影，不会使已删除家族复活。

本决策解决历史源码寻址，不解决因子注册整集合 JSON 的写放大及 512 KB 元数据载荷上限；后者已有独立增长测试证据，不能通过扩大载荷上限代替存储重构。
