# ADR-152：递归报告节与旧 subsection 兼容

状态：已接受（用户明确要求，2026-09-09）。关联 Issue #387。

报告的结构由 `parent_id` 定义。普通节统一使用 `section`，可递归包含 `section` 或 `special`；不再用节点类型限制深度。`chapter` 仍是报告根级章节。`special` 与 `display_kind` 表示特殊用途，不改变所在层级。

旧 CLI 输入 `subsection` 在新建节点时规范化为 `section`。读取旧节点时保留原字节及内容地址，不对既有历史作批量迁移；父子合法性校验与前端展示将该名称视为别名。循环引用、根节点限制及内容组件不可作为父节点的校验保持有效。

前端缩进和 Markdown 标题取决于祖先深度，同父的普通节和特殊节级别一致。Markdown 超过六级时使用六级标题，完整父子结构保留在规范报告树中。

验证覆盖旧节点无损读取、旧输入规范化、递归添加、批量移动、循环拒绝、普通和特殊同级标题，以及前端懒加载的同级布局。
