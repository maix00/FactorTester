# ADR-140：公共技术文档是经过维护的产品内容

> **编号迁移说明：** 本文原文件名为 `122-public-technical-documentation.md`。
> 因 ADR-122 已用于多币种账户和资金池估值，本文迁移为 ADR-140；决策内容不因重编号改变。

## 状态

已接受。

## 背景

FactorTester 过去把技术文档当作 Flask 模板和运行时 AST 浏览器，混合了用户
操作说明、系统架构说明和源代码展示，也使文档可用性依赖仓库布局和运行时扫描。

## 决策

公共技术文档模块承担两种同等职责：

1. 说明如何使用 FactorTester；
2. 说明功能如何实现以及规范代码入口在哪里，但不展示源码。

发布内容放在 `product_docs/` 并显式登记在 manifest；`docs/` 下的内部工程记录
不自动公开。实现页描述职责、流程、领域对象、规范路径、边界、生命周期、权限
和扩展点。

Manager 7998 拥有读取 API，并在现有 Web Shell 内渲染；macOS 客户端嵌入同一
路由，导航仍由外层客户端 tab 拥有。文档不需要账户即可阅读。

测试字段参考不是另一份手工字段表。它在用户打开参考页时，从测试设置注册表
生成当前客户端投影；Web、Swift 和 CLI 通过 `client` 参数选择同一注册契约的
视图，服务端负责筛选和分页。稳定入口是
`GET /api/docs/test-fields`，返回的字段类型、作用域、注册默认值和适用 tab
仅用于公开参考，不授予业务对象访问或提交权限。字段目录的延迟生成不改变文档
清单的启动校验，也不把内部 DOM 状态或框架变量扩展成公共字段。

`markdown-it-py` 仅用于受限 Markdown 解析，`nh3` 对渲染 HTML 执行标签、属性和
URL 白名单；原始 HTML 在清理前禁用，每个标题必须有明确稳定锚点，源码路径必须
在 manifest 声明的公共根目录内。搜索和导航由产品拥有，第三方文档壳不能另造
路由或认证系统。

## 后果

新增页面必须增加 manifest 条目和稳定标题锚点。运行时遍历源码树和展示源码不
属于文档功能；实现页中的代码路径只是导航线索，不是公开 API，也不授予访问
文件的权限。新增或修改测试字段时，应修改后端注册定义并由字段参考接口重新
生成，不能在 Web、Swift、CLI 或文档正文中复制一套默认值。用户指南和实现地图
可以相互链接并独立演进，与 ADR 和维护说明分离。
