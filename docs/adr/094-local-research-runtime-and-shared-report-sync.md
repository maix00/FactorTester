# ADR 094: 研究图运行态本地化与共享报告显式同步

> Graph catalog 与本地 Graph 文件要求已被 ADR-156 取代。共享报告显式同步及其不依赖当前 Profile 位置的要求仍有效；Graph 历史内容不迁移保留。

## 状态

已接受

## 背景

研究图的版本目录和研究过程状态混在 Manager 中，会使本地研究依赖
7998、服务器数据库和服务器在线状态。研究图本身是可下载的声明式 YAML；
研究 Agent 的选边、事实判断、因子计算和本地测试不应由 Manager 代为决定。

## 决策

1. Manager 只负责研究图目录：版本登记、版本列表、默认版本指针、语言版本、
   YAML/JSON 下载，以及用户研究图的上传、列表、下载和删除。Manager 不运行
   常驻研究 Agent，也不负责解释图、选择下一条边、执行因子或运行本地测试。
2. Swift/CLI 的本地运行时保存研究会话状态：图引用与版本、实例和分支标识、
   当前节点、选中的边、义务、事实/证据引用、报告绑定和本地运行记录。
   这些状态在本地持久化，不以 Manager 的研究实例表为权威。
3. Agent 根据本地研究图文件和本地事实决定下一步。Manager 不返回有序
   `next_actions`、推荐边、命令或 Agent 配额。
4. 用户明确共享研究报告时，客户端才向 Manager 发布一个报告进度投影。投影
   可以包含图 ID/版本、语言、已发布节点/边进度、报告章节和证据引用；未共享
   的本地义务、私有事实和完整本地会话不上传。共享并不改变本地优先原则：
   报告始终先写本地，服务器只接收可展示的投影。
5. 共享报告的附件和因子源码不进入 7998 JSON。先由 7998 获取短期授权，实际
   字节通过 7997 按需传输；本地运行包和本地生成物保留在执行它们的节点。
6. 服务器执行的任务仍由服务器保存 Job、任务状态和生成物；本地客户端只保存
   对应的远程 Job 引用。客户端选择本地运行时，测试代码、数据引用、提交物、
   运行态和生成物都留在本地隔离目录。服务器离线时，研究、报告编辑和本地
   测试继续可用。
7. 共享报告的同步采用本地 outbox：报告投影和 7997 对象先原子落盘，在线时
   立即尝试；网络断开时返回 `pending_sync` 并保留本地内容。恢复连接后，
   `research report publication sync` 或下一次 Manager 访问会重试。服务器拒绝
   或代际冲突标记为 `conflict`，不覆盖本地报告，也不自动丢弃队列。

## 迁移边界

现有服务器研究实例/分支接口暂时作为兼容读取和共享报告导入路径保留；新建的
本地研究不应依赖这些接口。后续迁移完成后，服务器端运行态表只保留已共享的
报告投影和必要的远程 Job 引用，再移除兼容写入。

## 后果

- 研究图导航、因子计算、测试和报告草稿可以在没有 Manager 的情况下运行。
- 服务器只需为图目录下载、显式报告共享和服务器任务提供服务；服务器不是
  研究运行时。
- 跨设备继续研究需要用户主动导出/导入本地会话，或共享报告；不会隐式复制
  私有研究过程。
- Swift 发布物不预置研究图、因子源码或测试运行包；用户选择本地运行时，才
  从选定 Manager 通过 7997 获取所需代码并放入隔离运行目录。共享报告断线时
  仍可编辑，恢复后只同步明确允许共享的投影和对象。
